# Archive — superseded material

This folder keeps the repo's pre-FaceValue planning and the research captures that are no longer on the critical path. Nothing here is part of the build or the submission.

Why archive instead of delete: this directory is not a git repository, so deletion would be irreversible. If you want it gone, remove `archive/` in one command after the submission.
